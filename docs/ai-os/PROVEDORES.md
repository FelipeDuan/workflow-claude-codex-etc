## Recomendação para Felipe

Para projetos pessoais com código e dados públicos, começaria comparando GLM-5.3-Flash via API com DeepSeek Flash em uma tarefa pequena e orçamento previamente definido. A GLM tem menor tarifa de saída nesta consulta e um DPA API mais explícito sobre armazenamento de conteúdo. A DeepSeek pode ser barata com cache e fora do pico, mas a política de dados da API continua com lacunas. Isso é uma recomendação de teste, sem afirmar qualidade, latência ou consumo real, que não foram medidos.

Com renda limitada, evitaria contratar várias mensalidades e o plano Alibaba de US$ 50 antes de medir consumo. Consideraria GLM Coding Plan Lite a partir de US$ 18 somente se uso recorrente justificar a mensalidade e as cotas por créditos couberem no trabalho. Não escolheria NVIDIA trial como ferramenta diária para entregas reais: disponibilidade e termos de produção são obstáculos. Kimi exige atenção ao preço de saída e ao uso de conteúdo para treino na API.

Projetos pessoais privados também podem conter dados pessoais sensíveis, credenciais, documentos de terceiros ou informações sigilosas. Remover esses dados antes do envio; “pessoal” não significa autorização para compartilhar. Para conteúdo institucional/SEPLAN, nunca enviar a nenhum desses provedores sem acordo e autorização institucional que cubram finalidade, retenção, treino, localização, operadores e transferência dos dados. Conta pessoal ou assinatura de coding não substitui esse acordo.
